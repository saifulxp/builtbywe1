### Share the movement
The **Share the movement** button uses the browser's native Web Share API. On supported browsers and devices it opens the operating-system share sheet (such as the macOS share menu shown in the design reference). For local testing, serve the site from `http://localhost` rather than opening `index.html` directly; production sharing should run on HTTPS. Browsers without Web Share support use a copy-to-clipboard fallback.
